# ENGLISH
Autonomous Potential Violation Eradicator (A.P.V.E) Made by 48h_48m_48s 
This plugin allows you to keep your server chat clean at any time, without the intervention of the administration. 
Advanced settings will allow you not only to disable certain modes, but also to set up offline issuance of punishments. 
This plugin works on the PacketEvents

A.P.V.E Version --> 1.0.0

1. How to install the plugin?
First, you need to put PacketEvents plugin (Spigot version, not proxy like BungeeCord or Velocity!) and any punishments-adds-plugin (Like EssentialsX) in the server's plugins directory for the plugin to work correctly. 
Make sure you download the plugins from the creator's official website. 
After putting the plugins to the server's plugins directory, put A.P.V.E .jar file at the same directory.

2. Which core version i should use?
A.P.V.E supports any bukkit-based-core (Paper, Purpur, Spigot) version between 1.20.5 and 26.2+ but recommended version to use are 1.21.4 and newer.

3. What license does the A.P.V.E use?
A.P.V.E. uses a GPLv3 license.


4. What if i don't put the punishment-adds-plugin in the server's plugins directory?
A.P.V.E will continue to work, however, punishments will not work correctly.


5. Can i use the A.P.V.E in my own server?
You can legally use A.P.V.E on your own server, as long as your use does not violate the license.


6. How to change the parameters of the punishments/modes of A.P.V.E?
You can change the parameters of the banned-word list, punishments, their enability, their duration and other in the config.yml file. 

7. For what audience can the plugin work correctly?
The plugin was created exclusively for Russian and English-speaking audiences. 

Reminder for you:
You must setup this config before using the A.P.V.E. Not configuring this config can lead to false punishments and message-blockings. Also, configure the punishment command syntax for your punishment plugin if you want avoid crashs!!!

For russian and other administrators:
Normalizer converts any cyrilic symbols into latin alphabet. Consequently, the addition of new banned words must be fully in latin alphabet like (шлюха --> shlyuha).
Full normalization documentation you can see in documentation.txt


# RUSSIAN
Autonomous Potential Violation Eradicator (A.P.V.E) Автор: 48h_48m_48s
Этот плагин позволяет поддерживать чистоту чата вашего сервера в любое время, без вмешательства администрации.
Расширенные настройки позволят вам не только отключать определенные режимы, но и настраивать оффлайн-выдачу наказаний.
Этот плагин работает на PacketEvents

A.P.V.E Версия --> 1.0.0

Как установить плагин?
Сначала вам нужно поместить плагин PacketEvents (Spigot версия а не BungeeCord или Velocity!) и любой плагин на наказания в директорию plugins сервера для корректной работы плагина.
Убедитесь, что вы скачиваете плагины с официального сайта создателя.
После помещения плагинов в директорию plugins сервера, поместите .jar файл A.P.V.E в ту же директорию.

1. Какую версию ядра я должен использовать?
A.P.V.E поддерживает любую версию ядра (Paper, Purpur, Spigot) между 1.20.5 и 26.2+ но рекомендуемая использования версия это 1.21.4 и последние.
 
2. Какую лицензию использует A.P.V.E?
A.P.V.E. использует лицензию GPLv3.

3. Что если я не положу плагин наказании в директорию plugins сервера?
A.P.V.E продолжит работать, однако наказание игроков не будет работать корректно.

4. Могу ли я использовать A.P.V.E на своем собственном сервере?
Вы можете легально использовать A.P.V.E на своем сервере, до тех пор пока ваше использование не нарушает лицензию.

5. Как изменить параметры наказаний/режимов A.P.V.E?
Вы можете изменить параметры списки запрещённых words, наказаний, их включенности, их длительности и другое в файле config.yml.

6. Для какой аудитории плагин может работать корректно?
Плагин был создан исключительно для русской и англоязычной аудитории.

Напоминание для вас:
Вы должны настроить конфигурацию для A.P.V.E перед использованием. Отказ от настройки конфигурации может повлечь за собой ложные срабатывания и блокировка сообщении. Также, настройте конфигурцию синтаксиса команд если вы не хотите сбоев!!!

Для русских и других администраторов:
Нормализатор конвертирует кирилицу и другие символы в латиницу. Следовательно, добавление новых запрещённых слов должно быть полностью на латинском языке как (шлюха --> shlyuha)
Понную документацию нормализации вы можете посмотреть в documentation.txt
